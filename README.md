# 레일온 배포용 저장소

레일온 안드로이드 앱이 자동 업데이트를 확인하는 곳입니다. (코드는 비공개 저장소에 있어요)

- **앱 설치:** [Releases](https://github.com/gyhun32-cell/railon-release/releases/latest)에서 `railon.apk`를 휴대폰으로 내려받아 설치
- `latest.json` 최신 앱 버전
- `timetable/` 앱이 받아 쓰는 호남선 시간표
- `notices.json` 시간표 변경 감지·코레일 공지

비공식 앱입니다. 지연·운휴·임시 변경은 반영하지 않습니다.
